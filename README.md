# 소울칼리버 V (PS3) 한글 패치

> **내려받기:** [릴리즈 페이지](https://github.com/hospi0/soulcalibur5-kr-patch/releases/latest) — v0.9.
> 북미판 디스크(BLUS30736)용, **게임 버전 1.03(업데이트 설치)에서 RPCS3 로 확인**했습니다(업데이트 없는 1.00 은 시험하지 않음).
> 적용 방법·원본 MD5 는 묶음의 readme.txt 에 있습니다.
>
> 이 저장소에는 도구·번역 텍스트·작업 문서만 있습니다(게임 데이터·빌드 결과물 없음).

## 적용

1. `SoulCalibur5_PS3_KR_v0.9.zip` 을 풉니다.
2. `한글패치_적용.bat` 을 실행하고 ① 게임 폴더(`PS3_GAME` 이 있는 폴더) ② RPCS3 폴더(업데이트·DLC 를 깔았을 때, 아니면 그냥 Enter)를 끌어다 놓습니다.
3. 파일마다 원본 MD5 확인 → 원본 백업 → xdelta 적용 → 결과 MD5 확인 후 덮어씁니다.
   - 디스크: `text.cpk`·`cdata.cpk`
   - 업데이트(선택): `patch.cpk` — 온라인 메시지
   - DLC(선택): `DLC06`~`DLC13` 의 `dat.cpk` — 깔린 것만
   - 되돌리기는 `되돌리기.bat`.
4. RPCS3 의 시스템 언어를 **한국어** 나 **영어** 로 둡니다(둘 다 영어 자리 글을 읽고, 그 자리에 한글이 들어갑니다).

게임 실행 파일(EBOOT)은 건드리지 않고 글·글꼴 데이터 파일만 바꿉니다.

## 바뀌는 것

- 메뉴·옵션·도움말, 시스템 메시지(저장·로드 안내는 PS3 시스템 창도 한글)
- 스토리 대사와 자막, 승리·도발 대사
- 캐릭터 크리에이션(파츠·장비 이름), 칭호, 플레이어 라이선스
- 모든 캐릭터의 기술표(기술 이름·커맨드 설명)
- 온라인 메시지(1.03 업데이트), DLC 파츠 이름·설명
- 고해상도 한글 글꼴(한자 칸 64px)

메뉴 큰 제목(Story·Offline Play 등 장식 글꼴), 일본판에도 영문으로 나오는 표기, 이름 입력 글자판은 원문 그대로입니다.

## 만든 방법(요약)

- CRI CPK(ITOC) 읽기·다시 쌓기 — `tools/cpk.py`·`tools/cpkw.py`(바꾼 파일은 무압축으로 넣음).
- 글 표는 소울칼리버 IV 와 같은 XOR 스트림 암호 + 꼬리 서명 `sc4-text` — `tools/mscrypt.py`·`tools/mstext.py`. 일본어 자리(6)를 원문으로 번역해 영어 자리(0)에 넣습니다.
- 한글은 «대역 한자» 방식: 글꼴 텍스처(cdata 의 JIS 순서 한자 칸)에 한글을 그리고, 글에는 그 칸의 한자를 UTF-8 로 씁니다 — `tools/build.py`·`tools/font_hires.py`(4096² 고해상도). PS3 시스템 대화상자 줄은 진짜 한글.
- 영어 자리에만 있는 머리 코드 중 `$z`(크기)는 붙이고 `$m`(영문 전용 글꼴)은 뺍니다.
- 번역 → `tools/apply_fixes.py`(전편 용어 통일·거센소리·손질 `work/text/manual.tsv`) → `work/text/fixed/` → 빌드.
- 배포 묶음 = `tools/make_dist.py`, bat 시험 = `tools/dist_battest.py`.

작업 기록은 `docs/00_초기조사.md` 에 있습니다.
